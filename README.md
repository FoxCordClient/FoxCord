# Warning

> This is **NOT** the official [Discord client](https://discord.com/).
>
> FoxCord is made with **C#** and **WebView2** instead of **Electron** to provide a faster and smoother experience while reducing memory usage and avoiding many of the slowdowns Electron-based applications can have.
>
> Since the official Discord desktop client is **not open source**, I cannot simply port or modify all of its native features. Because of this, some Discord-exclusive desktop features may be unavailable. I may implement a few custom alternatives in the future whenever possible.
